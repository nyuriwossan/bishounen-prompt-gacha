各アーキタイプは `en`（英語の美形アンカー）・`nat`（自然文）・`desc`（日本語の説明）と、顔／目元／表情／体格／容姿傾向／衣装／ポーズ／雰囲気／世界観／年齢／色などへの好み（soft）を持つ。名前が年齢を含むタイプ（「若き」「青年」「老紳士」など）は年齢層を、髪を含むタイプ（「黒髪クール」「ウルフヘア」「マッシュ系」）は髪色・髪型・髪の長さを、「眼鏡の知性派」は眼鏡ありを hard 条件にしている。

## スキーマ

```ts
interface Option {
  id: string; ja: string; en: string[]; nat?: string; cat?: string; desc?: string; w?: number; tags?: string[]; hex?: string; src?: string;
  worlds?: string[];           // 世界観との相性（soft）
  lengths?: string[];          // 髪型が成立する長さ（hard）
  minShot?: 0|1|2|3|4|5;       // ポーズに必要な最小画角（hard）
  hands?: number;              // ポーズの空いた手 / 持ち物に必要な手（hard）
  gazeViewer?: boolean; eyesClosed?: boolean;  // 視線（hard）
  place?: "indoor"|"outdoor"|"semi"|"simple"; daylight?: "day"|"night"|"twilight"; outdoorOnly?: boolean; needs?: string[]; // 背景・時間・光（hard）
  culture?: string; upper?: string; lower?: string;  // 衣装：伝統衣装の文化（hard）・{c1}{c2} の色つき描写
  prefs?: Partial<Record<FieldId, string[]>>;        // 美形アーキタイプの好み（soft）
  outfitPrefs?: string[];      // 職業の衣装傾向（soft）
  requires?: string[];         // 成立条件（hard）例 "glasses:!none", "prop:#blade", "age:a18_24|a25_34"
}
```
