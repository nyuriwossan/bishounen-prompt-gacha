# 美青年錬成ガチャ

**〜イケメンとの出会いは一期一会〜**

何度引いても、美形しか出ない。年齢・美形タイプ・容姿傾向・髪・瞳・衣装・世界観・構図をガチャで錬成し、気に入った項目を固定したまま残りを何度でも引き直せる、画像生成AI向けの美青年プロンプトガチャです。完成したプロンプトはワンタップでコピーして、PixAI・NovelAI などにそのまま貼り付けられます。

公開URL（GitHub Pages）：<https://nyuriwossan.github.io/bishounen-prompt-gacha/>

- 画像そのものは生成しません。画像生成AIに渡す**プロンプト（文章）**を作ります。
- 外部API・ログイン・サーバーは使いません。保存はこの端末のブラウザ内だけです。一度開けば通信が切れても使えます。
  - オフライン用のキャッシュ（Cache Storage）は名前が `bpg-` で始まるものだけを使い、同じ `nyuriwossan.github.io` で公開している他のアプリのキャッシュには触れません。
- 登場人物は**成人の男性1名**です。「女性的な美形」を選んでも、人物の性別タグは男性のままです。

## 遊び方

1. 開くと、すでに1人錬成されています。下の **「美青年を錬成する」** で、固定していない項目がまとめて変わります。
2. 気に入った項目は行の **鍵** で固定。**サイコロ** はその1項目だけを引き直します。行そのものを押すと、分類と検索で候補を選べます（「採用後に固定する」は初期ON）。
3. **プロンプト** 画面で出力先（PixAI／NovelAI／汎用タグ／自然な英文／日本語設定）を選び、「プロンプトをコピー」。

そのほかの操作：

| 操作 | 内容 |
|---|---|
| ロック全解除 | 固定の印だけを外す。選んだ内容は消さない |
| 戻す／進む | 錬成・採用・固定の変更を取り消し／やり直し（Ctrl+Z／Shift+Ctrl+Z） |
| 同じ方向性で引く | 年齢・美形タイプ・容姿傾向・世界観・意匠を保って、他を引き直す |
| 服だけ着せ替え／髪だけ変える／表情・構図だけ | 該当する項目だけを引き直す |
| おまかせスタイル（22種） | 「現代・日常／幻想・世界観／美形・雰囲気／外見特集」の分類で切り替え。現代・日常のイケメン・ダウナー・きれいめカジュアル・王道・和風幻想・銀髪特集など。選ぶだけでは変わらず、「この方向で錬成」で反映 |
| 抽選モード | まとまり重視（初期）／バランス／カオス |
| 詳細な調合 | 顔立ち・肌・特徴・眼鏡・ひげ、職業・雰囲気・色彩、ポーズ・構図・持ち物、背景・光、獣人モード、画風・呼び名 |
| 禁断の調合（アンリミテッド） | 初期はOFF。ONにすると立場・拘束具（縄・鎖・手錠・リボン・触手・光の鎖など13種）・拘束位置・固定先・締め方・目隠し（布・革・レース・リボンなど12種）・衣装の乱れ・衣装の状態（汚れ・損傷・濡れを最大2件）を抽選。拘束の構図は立ち・座り・膝立ち・うつ伏せの15種。囚われの場所（地下牢・独房・尋問室・巨大な鳥籠・座敷牢・天蓋付きの寝室・魔法陣の祭壇・触手の巣）の背景8種と、おまかせスタイルの「禁断」5種（囚われの王子・触手の森・鎖と地下牢・リボンの贈り物・支配する側）は、ONのときだけ出る。頭上で吊る拘束は屋内だけ、衣装の鎖・ベルト類とは混ぜず、ネガティブに選ばなかった素材を入れる。「禁断演出だけ引き直す」付き。人物は成人男性1名のまま、首への拘束・負傷・露出は扱わず、`adult` などの語も出さない。OFFの間は一切出力しない |
| コスプレ衣装 | 初期はOFF。ONの間、衣装は必ずコスプレ枠15種（メイド服・ミニスカメイド・ビキニ・紐ビキニ・水着と開襟シャツ・ミニスカナース・ミニスカセーラー服・バニーボーイ・逆バニー・ミニスカチャイナ・ミニスカポリス・ミニスカサンタ・チアリーダー・ハーネスと開襟シャツ・サーカス団長）から引く。おまかせスタイルの衣装の条件より優先し、世界観は問わない。通常の衣装も手で選べる。獣人ONでは兎耳の衣装、禁断の調合ONではセーラー服を自動では引かず、セーラー服は禁断演出と、メイド服はリボンの拘束具と、ミニスカポリスは手錠と組まない。ミニスカやビキニには、長いスカートや海パンを避けるネガティブを衣装ごとに足す（ネガティブON時）。OFFの間はコスプレ衣装を抽選・選択できない |
| 眼鏡・特徴・持ち物 | 初期はOFF（出力しない）。「詳細な調合」のスイッチでONにすると抽選に含める。OFFの間は、眼鏡や持ち物を前提にするポーズ（眼鏡を押し上げる・抜刀など）も出ない |
| 保存 | お気に入り（300件まで）・履歴（直近50件）・改名・メモ・複製・別衣装版・JSON入出力・Markdown・共有URL |

### 抽選モードの違い

| モード | 動き |
|---|---|
| まとまり重視 | 美形タイプ・世界観・職業に合う衣装・背景・表情を強く優先し、相性の悪い長い裾を切る |
| バランス | 相性の良い候補を優先しつつ、意外な組み合わせも残す |
| カオス | 「男性1名・美形・成人」と物理的な矛盾の回避だけ守り、時代・文化・SFを自由に混ぜる |

4,200回の抽選で、世界観に合う衣装の割合は まとまり重視 95.5%／バランス 86.4%／カオス 36.4%、美形タイプの好みに合う割合は 83.0%／47.9%／7.2% でした（`docs/test-artifacts/mass-draw-report.json`）。

### どのモードでも守ること（hard 制約）

短髪と長髪専用の髪型、画角の外に出るポーズ、手が足りない持ち物、閉じた目とこちらを見る視線、夜の日光、屋内の雨・雪、別文化の伝統衣装の混在、同じ色のメインカラーと差し色、人の尖った耳と獣耳の同時指定、名前に年齢・髪を含む美形タイプ（「若き」「老紳士」「黒髪クール」「ウルフヘア」など）と食い違う年齢層・髪、OFFにした眼鏡・持ち物を前提にする候補、禁断の調合の組み合わせ（「する側」の自縛、縛った手で手を使うポーズ、目隠しと眼鏡、衣装にないネクタイ・ジャケットの着崩し、濡れの重複など）。固定した項目は黙って書き換えません。固定どうしが矛盾する時は錬成せず、衝突する項目・理由・解除候補を表示します。

珍しいだけの組み合わせ（現代スーツ×吸血鬼、近未来×東洋刺繍、中性的な容姿×筋肉質、60歳以上の美形など）は誤りとして扱いません。

### シードについて

ラベル右上の seed を「抽選の設定」で固定すると、同じ辞書の版・同じ固定と設定なら同じ美青年を再現できます。画像生成サービス側の seed とは別物です。

### 「必ずイケメン」について

全出力に男性1名・美形の構造化アンカー（`1boy, solo, male focus, handsome` と美形タイプ固有の描写）を入れますが、実際の画像の仕上がりはモデル・LoRA・設定によって変わります。美しさを数学的に保証するものではありません。`adult male` は既定出力に強制挿入しません（年齢は `young man` などで表します）。PixAI・NovelAI向け形式は、よく使われるタグの書き方に合わせた整形で、各サービスの公式な最適化ではありません。

## 開発

Node.js 20 以降（CI は 22）。パッケージマネージャーは npm に統一しています。

```bash
npm install
npm run dev          # 開発サーバー
npm test             # 単体・結合・性質テスト（3,600回抽選を含む）
npm run build        # 型検査 + 本番ビルド（dist/）
npm run lint         # ESLint
npm run test:browser # ブラウザ検証（要：npm run build、Playwright 用 Chromium）
npm run report:examples  # docs/EXAMPLES.md の10名を再生成
npm run report:verify    # docs/VERIFY-SET.md（禁断の調合の実機確認20例）を再生成
```

`vite.config.ts` は `base: './'` で相対パス出力にしており、GitHub Pages のサブパス（`/bishounen-prompt-gacha/`）でも動きます。

### 公開（GitHub Pages）

`main` へ push すると `.github/workflows/deploy-pages.yml` が型検査・lint・テスト・ビルドを行い、`dist/` を `gh-pages` ブランチへ反映します。Pages の公開元は **Settings → Pages → Build and deployment → Deploy from a branch：`gh-pages` / `(root)`** です（`gh-pages` ブランチの作成時に自動で有効になります。表示されない場合だけ手動で選んでください）。

### 構成

```text
src/
  types/        スキーマ（Option, ForgeState, Selection …）
  data/         辞書（宣言的なTS）と imported/（既存ツールから抽出したJSON）
  engine/       シード付き乱数・状態・抽選（ロック/競合/修復）・soft 重み
  advisor/      hard 制約（hard.ts）と hard/soft/suggestion の説明（advisor.ts）
  prompts/      PixAI / NovelAI / 汎用タグ / 自然な英文 / 日本語 / Markdown
  storage/      自動保存・お気に入り・履歴・JSON・共有URL・移行
  ui/           Preact のUI（錬成・候補選択・プロンプト・保存・ヘルプ）
scripts/        import-sources.mjs（既存ツールからの再抽出）、examples.ts
tests/          vitest（data / engine / prompts / storage / mass-draw）と browser/
docs/           SOURCE-AUDIT / DATA-CATALOG / TEST-REPORT / EXAMPLES / screenshots / test-artifacts
```

辞書に候補を足すときは `src/data/*.ts` に1行加えます。候補IDを削除・改名する場合は `DATA_VERSION` を上げ、`src/storage/storage.ts` の `ID_RENAMES` に対応を書いてください（保存データの移行に使います）。テスト `tests/data.test.ts` が、ID重複・参照切れ・未成年や女性を示す語の混入を検出します。

### 設計上のトレードオフ

- **まとまりと多様性**：まとまり重視は「好みに合う候補群」に確率の下限を与え、さらに最有力候補の1割未満の候補を切ります。同じ美形タイプを引き続けると表情などが似やすいため、変化が欲しい時はバランスを使ってください。
- **職業**は画像に直接描きにくいため、衣装と持ち物の傾向づけに使い、出力タグには入れていません（日本語設定には表示）。
- **獣人モード**は顔の美形アンカーを保つため、ケモミミ〜標準獣人（顔は人に近い）までにしています。
- **フォント**は Google Fonts の Shippori Mincho を読み込みますが、取得できない環境ではシステムの明朝体で表示され、機能には影響しません。
